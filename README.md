# Bayesian-optimised attention Bi-LSTM on NinaPro DB1

Code for the manuscript *Bayesian-Optimised Attention Bi-LSTM for Surface-EMG Gesture Recognition on NinaPro DB1 under Leakage-Controlled Repetition and Leave-One-Subject-Out Evaluation with Attention Faithfulness Tests*.

Every number, table and figure in the manuscript is computed by these scripts from the per-run
result files included here (`run_*`). Nothing is entered by hand.

## Data

NinaPro DB1 (27 intact subjects, 52 movements + rest, 10 Otto Bock electrodes, 100 Hz):
M. Atzori et al., "Electromyography data for non-invasive naturally-controlled robotic hand
prostheses," *Sci. Data* 1, 140053 (2014), doi:10.1038/sdata.2014.53. Download the subject
archives from https://ninapro.hevs.ch (registration required) and unzip them into one folder
that holds `S{1..27}_A1_E{1,2,3}.mat`.

## Files

| File | Purpose |
|---|---|
| `prep_db1.py` | Concatenates exercises A–C, 200 ms windows every 100 ms with constant label and repetition, rest thinning |
| `core.py` | Data access, log-standardisation, Bi-LSTM, attention Bi-LSTM, TCN, training with gain/noise augmentation, search-space decoder, random search, GP Bayesian optimisation, metrics |
| `tune.py` | Panel-level search (shared initial design `INIT`, then `BO` or `RS`) on validation repetitions 9, 10 |
| `panel_ref.py` | Manual configuration, Bi-LSTM, TCN and SVM on the same panel validation repetitions |
| `final.py` | Per-subject training on reps 1, 3, 4, 6, 8, 9 (early stop on 10), test on 2, 5, 7; `ATTN_BO_FULL` refits on all 7 reps |
| `classical.py` | LDA, RBF-SVM and random forest on 50 envelope features |
| `leak.py`, `leak_overlap.py` | Random-window versus repetition partition; dependence on window overlap |
| `loso.py` | Leave-one-subject-out with calibrated or global normalisation |
| `probe.py` | Attention faithfulness (deletion, sufficiency, saliency) and robustness (gain, noise, electrode loss, rotation) |
| `efficiency.py` | Parameter counts and single-window CPU latency |
| `analyze.py` | All statistics → `results.json` |
| `fig_diagrams.py`, `fig_results.py` | All figures (grayscale) |
| `run_all.sh` | Complete pipeline in order |
| `restore_runs.py` | Rebuilds the `runs/` layout from the flat `run_*` files |
| `run_*` | Per-run results (search logs, selected configurations, per-subject metrics, LOSO, leakage, probes) |
| `results.json`, `db1_info.json` | Analysis output and window counts |

Per-window logits (`*.npz`) and model weights (`*.pt`) are regenerated by `final.py`; they are needed
by `probe.py` and by the calibration and per-class parts of `analyze.py`.

## Reproduce

```bash
pip install -r requirements.txt
RAW=/path/to/ninapro_db1 DB1=db1 sh run_all.sh        # more than a day on two CPU cores
```

Seeds: panel 2026, search candidates and GP sampler 17, network initialisation 0 (seed study 1, 2),
leave-one-subject-out subsampling 1000 + subject. Software used for the manuscript: Python 3.13,
PyTorch 2.14.1 (CPU), scikit-learn 1.9.1, SciPy 1.18.1, Optuna 5.0.0.
